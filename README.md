# India economy dashboard (working title in `site.config.yaml`)

A free, daily-updated read on the Indian economy: growth, prices, jobs, activity, money and banking, markets, public finances, the external sector and states. It includes a release calendar, downloadable data, and human-approved briefings.

Inspired by [econvitals.org](https://econvitals.org). Independent and not affiliated.
