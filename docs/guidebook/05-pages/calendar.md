# Calendar

**Purpose:** What is released when, and what did the last print show?

## Must include
- [ ] Month view and list view of upcoming releases (MoSPI ARC, RBI MPC and WSS, CGA, Commerce, Labour Bureau, OEA, GST)
- [ ] For each row: date, time (IST, if known), indicator, period covered, previous value, and the latest value once released (links to chart)
- [ ] "Estimated" badge when the date is our inference, not a published calendar
- [ ] Union Budget day and MPC meetings highlighted
- [ ] .ics feed (all, or per category)
- [ ] Generated entirely from `registry/calendar/*.yaml`

## Must NOT include
- Consensus forecasts we can't source freely and attribute (add later only if a free source exists)
