# Calendar

**Purpose:** What is released when, and what did the last print show?

## Must include
- [x] Month view and list view of upcoming releases (list grouped by month) (MoSPI ARC, RBI MPC and WSS, CGA, Commerce, Labour Bureau, OEA, GST)
- [x] For each row: date, time (IST, if known), indicator, period covered, previous value, and the latest value once released (links to chart)
- [x] "Estimated" badge when the date is our inference, not a published calendar
- [x] Union Budget day and MPC meetings highlighted (MPC done; Budget day to add when announced)
- [x] .ics feed (all releases; per-category feeds to add) (all, or per category)
- [x] Generated entirely from `registry/calendar/*.yaml`

## Must NOT include
- Consensus forecasts we can't source freely and attribute (add later only if a free source exists)
