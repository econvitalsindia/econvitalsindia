# Tools (index)

**Purpose:** Deeper interactive tools on narrower questions.

## Planned tools (Phase 4+), in priority order
- [ ] **MPC Speak**: hawk–dove score (−3…+3) for each MPC member's statement in each set of minutes, scored by an LLM with a published rubric. Shows member trajectories and committee drift. The scored text is shown alongside every score
- [ ] **Surprise composites**: activity and inflation z-scores vs history (and vs consensus, if a free consensus source appears)
- [ ] **RBI policy rule**: Taylor-type rule with user-chosen neutral rate, inflation gap (headline/core), output gap (HP/production function), vs actual repo
- [ ] **Union Budget explorer**: BE/RE/Actuals by ministry and major heads, over time
- [ ] **Monsoon and food watch**: rainfall vs LPA by subdivision, reservoir storage, daily prices of key vegetables, vs CPI food
- [ ] **Base-year bridge explorer**: old vs new base series in the overlap period
- [ ] **India vs peers**: growth, inflation and policy rates vs EM peers (IMF/World Bank data)

## Must NOT include
- Tools that need a server at runtime (everything precomputed or client-side)
