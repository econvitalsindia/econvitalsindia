# 0004 · AI drafts, a human approves

**Date:** 2026-10-28 · **Status:** accepted

**Decision:** Briefings are drafted by an LLM into a PR. A human merge is the only path to publish or email. Numbers come only from the ledger (see `07-editorial-policy.md`).
**Why:** a new site's credibility depends on zero factual errors. Econvitals publishes unreviewed AI text, but it has an established reputation and a heavy verification stack.
