# Release calendars

One yaml per publisher (`mospi.yaml`, `rbi.yaml`, `cga.yaml`, `commerce.yaml`, `oea.yaml`, `labour_bureau.yaml`).
Each entry: `{date, time_ist, series_ids, period, estimated: bool, source_url}`.
Sources: MoSPI Advance Release Calendar (PDF, updated through the year), the RBI MPC schedule (announced each FY), and others as scouted.
Populated in Phase 1.
